# バッチH：検出・文書取込・検索の検証

K04・N04・K03を対象に、途中だった埋め込みとハイブリッド検索を完成し、PDF/DOCX/PPTX/XLSXのローカル取込、選択フォルダーの監視、スレッド単位の検出、コーチ応答の取得範囲カードを接続しました。実モデルは呼びません。検出の登録は本人確認専用のままです。

## 実装と境界

- 資料の索引は本人操作で作成します。IPv4/IPv6のIPリテラルloopback・明示ポートのHTTPだけに送信し、APIキー・DNS・redirectは使いません。N10のNetworkGatewayを経由し、offline_onlyでは下位fetchを呼びません。64入力・32,000文字、10秒、応答8MiB、4,096次元の上限を設け、番号と件数も検査します。
- 所有者・取得/保存/索引許可・保持期限・期間を採点前に確認します。文字一致と意味検索をRRFで統合し、引用は元のspan・版・文字位置・文書位置に結び付けます。モデル・接続先・次元・資料版/hash・許可版の異なる索引は使いません。停止時は文字検索へ戻ります。コーチ会話とPWAは文字検索です。
- 文書は25MiB以内、workerは20秒・heap 256MiBです。ZIPの展開量・件数・圧縮比・経路、XML、暗号化を検査します。原ファイルは保存せず、抽出本文・全ファイルhash・位置・未読情報を保存します。PDFのテキスト層、DOCXの段落、PPTXのスライド、XLSXのシート/セルを扱い、数式・マクロ・リンクは実行しません。画像・図・OCR・レイアウトは未確認として示します。
- 監視は起動中の本人が選んだ専用フォルダーだけです。秘密情報のフォルダー、symlink/junction/hardlink、外への経路を拒否します。更新を保留し、安定した本文のプレビューと本人の保存操作を経て同じ資料IDの新しい版にします。欠落は取消根拠にしません。自動AI呼出・自動検出・自動タスク登録はしません。
- 同じ会話から本人が選んだ最大20資料・合計50,000文字を日時順に検出器へ渡します。後の訂正・取消を含められ、いずれかの資料の版/許可変更はrun全体を失効させます。所属/承認済みルールと不要根拠の台帳・抑制も版を検査します。
- コーチ応答に、資料の取得範囲・欠落期間・固定版の引用を端末内で計算したカードとして保存します。AIが全履歴を断定した場合は注意を添えます。AI送信未許可の資料は端末内の参照だけに使えます。
- 凍結/読み取り専用では取込・改訂・文書読取・埋め込み・検出の開始と確定を止めます。K12の登録経路、N09のreview-only、K08の送信許可、K11の削除/期限/許可取消による派生物消去を維持します。embeddingはバックアップと外部引継ぎに出しません。
