# michi — キャラクターコーチToDo

キャラクターコーチToDo設計パック v1.3（2026-09-28）を基準にした、端末単独版の実装です。このリポジトリにはアプリのソースコードを収録しています。

## 起動

Node.jsとnpmを用意し、このリポジトリのルートで以下を実行してください。

```powershell
npm ci
npm run desktop
```

Windows用ポータブル版を作る場合は `npm run package:win` を実行します。日時付きのフォルダーが `release` に生成され、その中の `michi.exe` で起動できます。`release` はGitHubに含めていません。HTTPサーバー、ログイン、APIキーは不要です。保存先は実行したWindowsユーザープロファイル内のアプリ専用IndexedDBです。

開発時は `npm run dev`。型検査とビルドは `npm run build`、自動テストは `npm test`、静的検査は `npm run lint`。ブラウザ版は初回の読み込み後、同じブラウザの保存領域にデータを保持します。デスクトップ版とは別の保存領域です。

## 実装済み

- 手動タスク作成・編集・検索、Inbox相当の一覧、予定日と締め切りの分離、プロジェクト名・ラベル・重要度、ゴミ箱と復元
- 未設定・手動0pt・手動値・式計算・推定範囲の区別。設計書第6章の既定式
- IndexedDBのローカル正式保存、revision競合、command key再送抑止、評価履歴、完了・取消・再完了・訂正の台帳
- 今日、7日計画と時間／ポイント容量、集中タイマーと作業時間、実績画面
- 日・週・月・完了後のローカル繰り返し、安定した発生回キーによる重複防止
- アプリ内キャラクターと保存済みタスクに基づく**定型**対話。外部AI推論や資料検出を実行したようには表示しません
- パスワード由来鍵（PBKDF2-SHA256）とAES-256-GCMによる `.coachbundle` 書き出し／整合確認後の復元
- Windows用Electronシェル。アプリは同梱ファイルだけを読み込み、外部ネットワークリクエストを拒否します

## 未実装・未検証

この版は設計書の121要件を完了した製品ではありません。AIによる意味的な必要タスク検出、BYOK会話、承認／Policy Engineの完全な代理変更、MCP・ChatGPT／Claudeプラグイン、外部メール／カレンダー／メッセンジャー連携、GitHub実績、スマホネイティブ通知、共有、サーバー接続型と複数端末同期、Live2D／音声、分割予算・外出束、業務カレンダーの例外処理は未実装です。設定画面ではAIと通知をOFF／未提供と表示します。

実機の受入24条件・外部プラグイン40条件は通過していません。検証済みはTypeScriptビルド、8件のローカルドメインテスト、ブラウザ上の手動タスク作成・25pt完了・台帳表示・日付保存です。Electron版は起動プロセスを確認しましたが、画面上の全操作を別途実機検証する必要があります。

## データについて

バックアップのパスワードは復元時に必要です。紛失するとアプリは回復できません。復元は現在のデータセットを置き換えるので、必要なら事前に書き出してください。ブラウザデータを消すと端末内データも失われるため、定期的に外部保存先へ書き出してください。
