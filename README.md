# michi — キャラクターコーチToDo

キャラクターコーチToDo設計パック v1.3（2026-09-28）を基準にした、端末単独版の実装です。このリポジトリにはアプリのソースコードを収録しています。

## 起動

Node.jsとnpmを用意し、このリポジトリのルートで以下を実行してください。

```powershell
npm ci
npm run desktop
```

Windows用ポータブル版を作る場合は `npm run package:win` を実行します。日時付きのフォルダーが `release` に生成され、その中の `michi.exe` で起動できます。`release` はGitHubに含めていません。HTTPサーバー、ログイン、APIキーは不要です。保存先は実行したWindowsユーザープロファイル内のアプリ専用IndexedDBです。

開発時は `npm run dev`。型検査とビルドは `npm run build`、自動テストは `npm test`、静的検査は `npm run lint`。ブラウザ版は初回の読み込み後、同じブラウザの保存領域にデータを保持します。デスクトップ版とは別の保存領域です。

## 実装済み

- 手動タスク作成・編集・検索、Inbox相当の一覧、予定日と締め切りの分離、プロジェクト名・ラベル・重要度、ゴミ箱と復元
- 未設定・手動0pt・手動値・式計算・推定範囲の区別。設計書第6章の既定式
- IndexedDBのローカル正式保存、revision競合、command key再送抑止、評価履歴、完了・取消・再完了・訂正の台帳
- 今日、7日計画と時間／ポイント容量、集中タイマーと作業時間、実績画面
- 日・週・月・完了後のローカル繰り返し、安定した発生回キーによる重複防止
- アプリ内キャラクターの定型対話。Windowsデスクトップ版では任意のOpenRouter接続で、送信文と選択した1件のタスクについてAIに相談できます
- パスワード由来鍵（PBKDF2-SHA256）とAES-256-GCMによる `.coachbundle` 書き出し／整合確認後の復元
- Windows用Electronシェル。画面からの外部ネットワークリクエストは拒否し、本人がAIチャットを送信した場合だけメインプロセスからOpenRouterへ接続します

## 任意のOpenRouter接続

Windowsデスクトップ版の「コーチ」画面でモデルIDとAPIキーを設定します。既定のモデルIDは `deepseek/deepseek-v4.1-flash` です。キーはOSの暗号化保存を使って端末内に保存し、GitHubや `.coachbundle` バックアップには含めません。接続を削除するとキーも端末から削除します。ブラウザ版にはAPIキー入力を提供していません。

AIチャットは送信した文章と、画面で選択したタスク1件のタイトル・メモ・予定日・期限・ポイントだけをOpenRouter経由で選択したモデルの提供先へ送ります。初期状態ではタスクは選択されていません。過去の会話や他のタスクは自動送信しません。AIの返答からタスクを自動で作成・編集・完了する機能はまだありません。キー未設定またはオフラインのときは従来の定型応答を利用できます。

## 未実装・未検証

この版は設計書の121要件を完了した製品ではありません。AIによる意味的な必要タスク検出、承認／Policy Engineの完全な代理変更、MCP・ChatGPT／Claudeプラグイン、外部メール／カレンダー／メッセンジャー連携、GitHub実績、スマホネイティブ通知、共有、サーバー接続型と複数端末同期、Live2D／音声、分割予算・外出束、業務カレンダーの例外処理は未実装です。設定画面では通知を未提供と表示します。

実機の受入24条件・外部プラグイン40条件は通過していません。検証済みはTypeScriptビルド、11件のローカルテスト、ブラウザ上の手動タスク作成・25pt完了・台帳表示・日付保存、Windows Electronでのブリッジ起動と合成文によるOpenRouter応答です。Electron版の画面上の全操作を別途実機検証する必要があります。

## データについて

バックアップのパスワードは復元時に必要です。紛失するとアプリは回復できません。復元は現在のデータセットを置き換えるので、必要なら事前に書き出してください。ブラウザデータを消すと端末内データも失われるため、定期的に外部保存先へ書き出してください。
